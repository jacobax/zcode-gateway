多账号策略

  • 会话分散新会话在健康账号中随机分配，避免请求集中到单个账号。
  • 会话粘性同一会话固定到同一账号，直到额度耗尽、异常或粘性过期。

账号管理

拖动排序会影响调度优先级；新会话随机分配，后续按会话 ID 粘性。

怎么添加账号？两种方式怎么选

浏览器登录授权（推荐）：点「添加账号」，复制回调地址，在浏览器里登录 z.ai，再把跳转后的地址粘回来。凭据由网关自己换，不用手工抓 cookie，新号走这条。

导入本机账号：直接读本机 ZCode 桌面端的登录态（~/.zcode/v2/credentials.json）。只适合「把自己正在用的号搬进来」；没装桌面端或没登录过就会提示没凭据。首次启动账号表为空时也会自动导入一次，日志里有记录。

加完记得：没有套餐的号先禁用，否则会被选号选中并把上游的 1005 exceed quota limit 原样透传给客户端。额度可以交给 contrib/claimer 自动领取。
